# ContadoraTeresa.com

Site profissional de campanha para **Teresa Castro** — contabilidade e gestão para candidaturas na Eleição 2026.

## Conteúdo

- Apresentação da estrutura do escritório e facilitadores digitais (contratos, notas, gestão)
- Checklist interativo para solicitação de orçamento de campanha
- Identidade visual alinhada à marca (roxo `#280858` sobre fundo escuro)

## Desenvolvimento

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
npm run preview
```

## Contato do formulário

O checklist abre o cliente de e-mail com destino `contato@contadorateresa.com`. Ajuste o endereço em `src/components/QuoteChecklist.tsx` e no rodapé, se necessário.
